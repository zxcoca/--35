1. git init - инициализация нового локального репозитория.
2. git clone [url] - клонирование удаленного репозитория на локальный ПК.
3. git status - проверка текущего состояния рабочего дерева и индекса.
4. git add [файл] - добавление файла в индекс (подготовка к коммиту).
5. git commit -m "сообщение" - фиксация изменений (создание коммита).
6. git push - отправка локальных коммитов в удаленный репозиторий.
7. git pull - получение изменений из удаленного репозитория и слияние их.
8. git branch - просмотр, создание или удаление веток.
9. git checkout [ветка] - переключение между ветками.
10. git log - просмотр истории коммитов.
